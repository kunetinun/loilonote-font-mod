# LoiLoNote Font Selector MOD

ロイロノート Web版 (https://loilonote.app/) にフォント選択機能を追加するMODです。

## 使い方 (Chrome 拡張)

1. `loilonote_font_mod_extension` フォルダを Chrome の `chrome://extensions` で「パッケージ化されていない拡張機能を読み込む」から読み込む。
2. https://loilonote.app/ を開く。
3. 画面左下の「Font」ボタン、または拡張機能アイコンでパネルを開く。
4. フォントを選択し「全体に適用」または「選択テキストに適用」。

## 使い方 (スクリプト注入 / Safari ショートカット)

1. `loilonote_font_mod.js` をダウンロード。
2. Web版ロイロノートを開き、ブラウザのコンソールまたはショートカットでスクリプトを実行。

## 注意

- ロイロノートのDOM構造に依存するため、バージョンアップで動作しなくなる可能性があります。
- アイコンフォントが崩れる場合は「アプリ全体に適用」のチェックを外し、選択テキストのみに適用してください。
